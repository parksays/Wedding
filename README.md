# Shafiya & Ifroz — Wedding Invitation

A mobile-first, Instagram-Reels-style vertical wedding invitation.

## Files
- index.html
- style.css
- script.js
- music.mp3 (optional — add your own song)

## Run locally
Open `index.html` in a browser.

## Deploy on Vercel
1. Create a GitHub repository and upload these files.
2. Go to Vercel and import the repository.
3. Framework Preset: Other
4. Build Command: leave empty
5. Output Directory: leave empty
6. Deploy.

## Add music
Put a file named `music.mp3` beside `index.html`.
Browsers generally require a user tap before playing music.
